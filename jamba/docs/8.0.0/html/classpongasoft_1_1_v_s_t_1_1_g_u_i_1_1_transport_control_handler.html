Detailed Description

This class is a thin wrapper around the ITransportControl interface to expose it as convenient methods rather than opaque actions.

Jamba gives access to the transport control actions via 2 methods on the GUIController class as well as on the state.

// Example from the state
// 1. Access via the transport control handler
fState->getTransportControlHandler().playbackStart();
// 2. Access via the low level interface
auto controls = fState->findTransportControl();
if(controls)
{
controls->playbackStart();
}
